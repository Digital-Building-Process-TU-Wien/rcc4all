The `ids_checker` node validates the loaded IFC model against an IDS specification file.

Use this node when you need to verify that the IFC model meets the requirements defined in an IDS file.

## Use case example

Check if the IFC model contains all required elements, properties, and classifications as specified in a project's IDS specification.
