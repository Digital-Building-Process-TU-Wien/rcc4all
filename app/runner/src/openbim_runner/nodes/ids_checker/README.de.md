title: IDS-Prüfer
description: Validiert das IFC-Modell gegen eine IDS-Datei (Information Delivery Specification).
categories: Validation
---

Der `ids_checker` Knoten validiert das geladene IFC-Modell gegen eine IDS-Spezifikationsdatei.

Verwenden Sie diesen Knoten, wenn Sie überprüfen müssen, ob das IFC-Modell die in einer IDS-Datei definierten Anforderungen erfüllt.

## Anwendungsbeispiel

Überprüfen Sie, ob das IFC-Modell alle erforderlichen Elemente, Eigenschaften und Klassifikationen enthält, wie in der IDS-Spezifikation des Projekts festgelegt.
